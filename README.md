# 🎨 Vibe Coding

一个充满活力的编程项目集合，包含各种有趣的小项目和实践代码。

## 📚 项目简介

Vibe Coding 是一个用于探索和实践编程的项目仓库，旨在通过有趣的项目来学习和提升编程技能。每个项目都是独立的，可以直接运行和使用。

## 🎯 项目列表

### 🐍 [贪吃蛇游戏](./1_贪吃蛇/)

一个基于网页的经典贪吃蛇游戏，使用 HTML5 Canvas 和原生 JavaScript 开发。

**特性：**
- 经典贪吃蛇玩法
- 得分系统和最高分记录
- 响应式设计，支持桌面端和移动端
- 数据持久化（LocalStorage）

[查看详情](./1_贪吃蛇/README.md)
