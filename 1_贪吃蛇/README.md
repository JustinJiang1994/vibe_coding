# 🐍 贪吃蛇游戏

一个基于网页的经典贪吃蛇游戏，使用 HTML5 Canvas 和原生 JavaScript 开发。

## ✨ 功能特性

- 🎮 **经典玩法**：控制蛇吃食物，每吃一个食物蛇会变长，得分增加
- 🎯 **得分系统**：实时显示当前得分和最高分记录
- 💾 **数据持久化**：最高分自动保存到浏览器本地存储
- ⏸️ **暂停功能**：支持游戏暂停和继续
- 🎨 **现代化UI**：美观的渐变背景和圆角设计
- 📱 **响应式设计**：支持桌面端和移动端，移动端提供触摸按钮控制
- 🎪 **游戏结束提示**：友好的游戏结束界面，可快速重新开始

## 🚀 快速开始

### 方法一：直接打开
1. 下载或克隆项目到本地
2. 用浏览器打开 `index.html` 文件即可开始游戏

### 方法二：使用本地服务器
```bash
# 使用 Python 3
python -m http.server 8000

# 使用 Node.js (需要安装 http-server)
npx http-server

# 然后在浏览器访问 http://localhost:8000
```

## 🎮 游戏操作

### 桌面端
- **方向键 ↑↓←→**：控制蛇的移动方向
- **空格键**：暂停/继续游戏

### 移动端
- 点击屏幕上的方向按钮控制蛇的移动
- 点击"重新开始"按钮开始新游戏

## 📋 游戏规则

1. 使用方向键控制蛇的移动
2. 吃到红色食物可以增长身体并获得 10 分
3. 撞到墙壁或自己的身体会游戏结束
4. 游戏结束后可以点击"重新开始"按钮重新开始
5. 最高分会自动保存，刷新页面也不会丢失

## 🛠️ 技术栈

- **HTML5**：页面结构
- **CSS3**：样式设计和响应式布局
- **JavaScript (ES6+)**：游戏逻辑实现
- **Canvas API**：游戏画面渲染
- **LocalStorage**：数据持久化

## 🔧 自定义修改

### 修改游戏速度
在 `game.js` 中找到 `setInterval(gameStep, 150)`，修改数字（单位：毫秒）：
- 数字越小，游戏越快
- 数字越大，游戏越慢

### 修改得分规则
在 `game.js` 中找到 `score += 10`，修改为你想要的分数。

### 修改颜色主题
在 `style.css` 中修改渐变背景色和游戏元素的颜色。

## 📝 开发说明

- 游戏使用 Canvas 2D API 进行渲染
- 采用网格系统管理游戏逻辑（20x20 网格）
- 使用 requestAnimationFrame 或 setInterval 实现游戏循环
- 碰撞检测包括边界检测和自身碰撞检测
