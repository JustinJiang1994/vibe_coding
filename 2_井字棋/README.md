# 井字棋游戏

一个功能完整、界面美观的井字棋（Tic-Tac-Toe）游戏，使用纯 HTML、CSS 和 JavaScript 开发。

## 功能特性

### 核心功能
- ✅ 3x3 棋盘游戏
- ✅ 双人对战模式（X 和 O 玩家轮流下棋）
- ✅ 自动判断胜负（横、竖、对角线）
- ✅ 平局检测
- ✅ 获胜单元格高亮显示
- ✅ 游戏状态实时显示

### 用户界面
- 🎨 现代化渐变背景设计
- 📱 响应式布局，支持移动端和桌面端
- ✨ 流畅的动画效果和交互反馈
- 🎯 清晰的视觉指示器

### 游戏管理
- 📊 得分统计（X 得分、O 得分、平局次数）
- 🔄 一键重置游戏
- 🎮 游戏结束后自动禁用操作

## 使用方法

### 本地运行

1. 克隆或下载项目到本地
2. 直接在浏览器中打开 `index.html` 文件
3. 开始游戏！

### 游戏规则

1. 游戏由两名玩家轮流进行
2. 玩家 X 先手，玩家 O 后手
3. 点击空白格子放置自己的标记
4. 率先在横、竖或对角线上连成三个相同标记的玩家获胜
5. 如果棋盘填满且无人获胜，则为平局

- Chrome
- Firefox
- Safari
- Edge

## 开发说明

### 主要功能实现

- **游戏状态管理**: 使用数组存储棋盘状态
- **胜负判断**: 通过预定义的获胜组合进行检测
- **得分统计**: 使用 localStorage 可扩展为持久化存储
- **响应式设计**: 使用 CSS Grid 和 Flexbox 实现
